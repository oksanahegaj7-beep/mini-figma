# AGENTS.md — правила работы с репозиторием

## Проект

`mini-figma/` — мини-редактор фигур (React 19 + TypeScript + Vite 8 + Tailwind CSS).
В корне репозитория — служебные файлы: конфиги агентов (`opencode.json`, `.agents/`, `.opencode/`), аудит (`AUDIT.md`), скрипты.

Код приложения живёт в `mini-figma/src`:

- `components/` — UI (Canvas, TopBar, панели);
- `hooks/` — состояние редактора (useShapes, useViewport, useHotkeys);
- `utils/` — чистая логика (geometry.ts, dom.ts);
- `constants/`, `types/` — константы и типы.

## Обязательная проверка перед коммитом

Выполняется в каталоге `mini-figma/`, обе команды должны пройти без ошибок:

```bash
npm run build   # tsc -b && vite build — проверка типов + сборка
npm run lint    # oxlint
```

## Правила git

- Работаем в ветках `refactor/*` / `feature/*`; `main` не трогаем без явного разрешения.
- Один коммит — одна логическая правка; сообщение описывает суть (можно ссылаться на пункт `AUDIT.md`).
- Мусор в коммиты не попадает: `node_modules/`, `dist/`, `.vite/`, `*.log` игнорируются корневым `.gitignore`.
- Автор коммитов — локальная git-идентичность репозитория; глобальный `git config` не менять.
- Remote не настроен: `git push` не выполняется, пока удалённый репозиторий не указан явно.

## Стиль кода

- Комментарии — на русском, коротко и по делу.
- Глобальные хоткеи не перехватываются в полях ввода (INPUT/TEXTAREA/contentEditable) — проверка `isEditableTarget` из `utils/dom.ts`.
- История (undo/redo) — снимки состояния; перетаскивание и ресайз фигуры — один шаг истории, а не запись на каждое движение мыши.
